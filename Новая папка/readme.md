# Training Planner (План тренировок)

## Автор
**ФИ:** [Кириченко Никита]  

## Описание
Графическое приложение  для планирования и учета тренировок. 
Приложение позволяет добавлять записи о тренировках, просматривать их в виде таблицы, фильтровать по типу и дате, а также сохранять данные локально в формате JSON.
## Стек
- **Язык программирования:** Python 3.12
- **GUI библиотека:** Tkinter
- **Формат данных:** JSON
- **Система контроля версий:** Git
